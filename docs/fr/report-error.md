# Signaler une erreur

Merci de nous aider a conserver des informations exactes. Ecrivez a **errors@beastofreincarnation.fyi** avec :

1. L URL de la page.
2. La phrase ou etape qui semble incorrecte.
3. Ce qui s est produit a la place.
4. La plateforme, la region et la version du jeu.
5. Une source publique ou une capture sans information personnelle, si possible.

Les signalements concernant la compatibilite, un paiement, une sauvegarde ou une etape risquee sont prioritaires. Un signalement ne devient pas un fait avant verification.
