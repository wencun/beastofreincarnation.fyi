# Quelle configuration PC faut-il ?

<div class="meta"><span>Derniere mise a jour : 4 aout 2026</span><span>Fiche Steam</span><span>PC Windows</span><span class="verified">Confirme officiellement</span></div>

<div class="quick-answer"><strong>Reponse rapide</strong>La fiche Steam officielle confirme un processeur et un systeme 64 bits, avec Windows 11 liste comme systeme minimum. Ne vous fiez pas a une liste de configuration devinee : verifiez les valeurs CPU, GPU, memoire et stockage directement sur la fiche officielle.</div>

## Etapes

1. Ouvrez Parametres Windows.
2. Choisissez **Systeme puis A propos**.
3. Confirmez que le type de systeme est 64 bits.
4. Confirmez votre edition de Windows.
5. Comparez votre materiel avec la fiche Steam actuelle.
