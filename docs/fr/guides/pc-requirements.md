# Configuration PC Beast of Reincarnation

<div class="meta"><span>Verifie le 16 aout 2026</span><span>Source : fiche Steam officielle</span><span>PC Windows</span><span class="verified">Configuration officielle</span></div>

<div class="quick-answer"><strong>Reponse rapide</strong>Beast of Reincarnation demande un PC 64 bits, <strong>16 Go de RAM</strong>, <strong>45 Go</strong> d’espace disponible sur SSD et DirectX 12. Le minimum officiel vise 1080p Faible a 40 FPS avec DLSS ou FSR ; la configuration recommandee vise 1080p Moyen a 60 FPS avec DLSS ou FSR3.</div>

## Configuration officielle

| | Minimum | Recommandee |
| --- | --- | --- |
| Systeme | Windows 10 ou Windows 11 (64 bits) | Windows 11 (64 bits) |
| Processeur | Intel Core i5-8400 ou AMD Ryzen 5 3600 | Intel Core i7-12700K ou AMD Ryzen 7 5800X |
| Memoire | 16 Go de RAM | 16 Go de RAM |
| Carte graphique | NVIDIA GeForce GTX 1070 (8 Go) ou AMD Radeon RX 580 (8 Go) | NVIDIA GeForce RTX 3060 (12 Go) ou AMD Radeon RX 6700 XT (12 Go) |
| DirectX | Version 12 | Version 12 |
| Stockage | 45 Go disponibles ; SSD obligatoire | 45 Go disponibles ; SSD obligatoire |
| Note de performance officielle | Faible, 1080p a 40 FPS avec DLSS (RTX serie 20–50) ou FSR1 (Performance) | Moyen, 1080p a 60 FPS avec DLSS ou FSR3 (Performance) |

## Verifier votre PC

1. Ouvrez **Parametres → Systeme → A propos** et confirmez que Windows est en 64 bits.
2. Verifiez le processeur et la RAM dans **A propos** ou le Gestionnaire des taches.
3. Dans le Gestionnaire des taches, ouvrez **Performances** pour verifier le modele de carte graphique.
4. Gardez au moins 45 Go libres sur un SSD.
5. Comparez votre materiel au tableau : satisfaire le minimum ne garantit pas l’objectif recommande de 60 FPS.

## En cas de plantage ou d’echec au lancement

Les specifications ne permettent pas de diagnostiquer chaque probleme. Evitez les modifications non verifiees du registre, du BIOS ou des sauvegardes. Notez le message d’erreur exact et consultez d’abord l’assistance officielle.
