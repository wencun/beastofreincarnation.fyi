# Report an Error

Thank you for helping keep answers accurate. Email **errors@beastofreincarnation.gg** with:

1. The page URL.
2. The exact statement or step that may be wrong.
3. What happened instead.
4. Platform, region, and game version.
5. An optional public source or screenshot with personal information removed.

High-risk reports involving steps, numbers, compatibility, payment, or save data are prioritized for review. A report is not published as fact until verified.
