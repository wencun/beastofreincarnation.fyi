# Beast of Reincarnation on Game Pass

<div class="meta"><span>Last checked: Aug 26, 2026</span><span>PC Game Pass · Xbox Series X|S</span><span class="verified">Official Xbox and Fictions sources</span></div>

**Officially confirmed:** Beast of Reincarnation is included with Game Pass on PC and is available for Xbox Series X|S. Xbox lists August 4, 2026 as the release date.

## Need DLSS, FSR, or ultrawide help on PC Game Pass?

Fictions’ v1.0.9 notes say the earlier Microsoft Store/Xbox PC problem that made upscaling features unavailable has been resolved. The same update adds DLSS/FSR frame-generation options and ultrawide support.

For the current official status and the details to collect if an option is still missing, see [PC Game Pass DLSS, FSR, and ultrawide support](/en/guides/troubleshooting/ultrawide-dlss-fsr-status).

## What to verify before you subscribe

Game Pass plans, cloud availability, regional catalogues, and download access can change. Check the live Xbox listing in your region before you pay or install.
