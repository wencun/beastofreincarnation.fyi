# What Are the PC Requirements?

<div class="meta"><span>Last updated: Aug 4, 2026</span><span>Version: Steam listing</span><span>Windows PC</span><span class="verified">Officially confirmed</span></div>

<div class="quick-answer"><strong>Quick Answer</strong>The official Steam listing currently confirms a 64-bit processor and operating system, with Windows 11 listed as the minimum OS. Detailed CPU, GPU, memory, storage, and recommended specifications are not yet shown in the source checked for this page. Do not rely on guessed requirement lists.</div>

## Before you start
- Use a 64-bit Windows 11 installation.
- Update your graphics driver through the GPU manufacturer.
- Keep free storage available, but note that the official capacity is not confirmed here.

## Steps
1. Open Windows Settings.
2. Select **System → About**.
3. Confirm that **System type** says 64-bit.
4. Confirm your Windows edition is Windows 11.
5. Compare the remaining hardware only after the official listing publishes full values.
## If this did not work
If the game fails to launch, capture the exact error and check the official support channel or Steam update notes. We will not recommend risky registry, BIOS, or save-file changes without reproduction.
