# What Should You Know Before Your First Hour?

<div class="meta"><span>Last updated: Aug 4, 2026</span><span>Version: Launch information</span><span>PC · PS5</span><span class="verified">Officially confirmed</span></div>

<div class="quick-answer"><strong>Quick Answer</strong>Expect a single-player action RPG built around Emma and Koo. Learn Emma’s movement, sword attacks, evasion, and parry timing first, then add Koo’s command skills. The game supports varied loadouts through skill trees, gear, and spirit stones, so avoid treating an unverified “best build” as mandatory during your opening hour.</div>

## Prerequisites
- Confirm your platform and local release timing.
- On PC, confirm a 64-bit Windows 11 system; full hardware values should be checked on the official store.
- No network requirement is confirmed for the single-player journey on this page.

## Steps
1. Review controls and accessibility options before the first encounter.
2. Practice moving and evading without attacking.
3. Learn one basic sword sequence for Emma.
4. Practice parrying a readable enemy attack.
5. Open Koo’s command menu and observe how the action slows.
6. Read each skill, gear, and spirit-stone description before spending resources.
## If this did not work
Lower the difficulty or adjust control and display options if available in your version. If a menu name differs, use the retail build’s wording; this guide avoids inventing exact values or unlock points.
