# Beast of Reincarnation Known Issues & v1.0.9 Patch Status

<div class="meta"><span>Last checked: Aug 30, 2026</span><span>Official-source tracker</span><span class="verified">No player speculation presented as fact</span></div>

<div class="quick-answer"><strong>Quick Answer</strong>The latest published official notes are for <strong>v1.0.9 / v1.007.000</strong>. This update adds ultrawide support and DLSS/FSR frame-generation options, fixes the Microsoft Store/Xbox PC upscaling issue from v1.0.8, and begins the rollout of skippable cutscenes. It does <em>not</em> state that every performance or crash report is resolved.</div>

## Officially released or fixed

| Topic | Current official status | What is confirmed |
| --- | --- | --- |
| Patch v1.0.9 / v1.007.000 | Released | Adds ultrawide support, DLSS/FSR frame generation, the first batch of skippable cutscenes, and technical/gameplay fixes. |
| Microsoft Store / Xbox PC upscaling unavailable | Fixed in v1.0.9 | Fictions says the issue introduced in v1.0.8 should now be resolved. Report any continuing problem with platform and hardware details. |
| Pre-order DLC issue | Officially marked fixed | The Steam Community lists the official pinned announcement “FIXED: Pre-Order DLC Issue.” Store entitlement checks may still be needed for an individual purchase. |
| Kiku “End of the Line” frame drop | Fixed in v1.0.8 | The official v1.0.8 notes list a fix for the severe drop when activating this Bloom Strike skill mod. |

## Reports that are not official fixes

A forum or Reddit report may identify a real problem, but one report does not prove its cause or a universal solution. This includes individual PC crashes, controller conflicts, mod issues, and hardware-specific graphical defects.

Before contacting support, record your platform, game version, GPU, driver version, exact reproduction steps, screenshots, and a crash dump if Windows created one.
