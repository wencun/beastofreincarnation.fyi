# Beast of Reincarnation Patch v1.0.10 (v1.008.000)

<div class="meta"><span>Published: Aug 28, 2026</span><span>Official Patch 4</span><span class="verified">Source-checked against Fictions Support</span></div>

<div class="quick-answer"><strong>Quick Answer</strong><strong>v1.0.10 / v1.008.000</strong> is the latest official patch note currently published by Fictions. It adds film-grain, chromatic-aberration, and cutscene post-processing toggles, alongside inventory, interaction, control, performance, and bug fixes. It does not state that every cutscene can now be skipped.</div>

![Official v1.0.10 patch summary: visual settings, cutscene post-processing, exploration and inventory, controls and fixes](/images/patch-v1-0-10-overview.svg)

## Visual and cutscene options

The official patch notes confirm these new options:

| Setting | What the official note says |
| --- | --- |
| Film Grain | Can be toggled on or off. |
| Chromatic Aberration | Can be toggled on or off. |
| Post-Processing in cutscenes | Can be toggled on or off. |

Open the game's settings after updating and look for the named options. The official notes do not specify a single universal menu path, so avoid assuming that each platform labels its settings identically.

## Exploration, materials, and inventory

Patch 4 also adds or changes the following:

- **Blight Sprouts** now yield SP in each zone.
- **Fractured Amber** nodes were added to select zones.
- When inventory capacity is reached, excess items are automatically converted into Amber.
- The interaction range for standard items was increased.
- Items already at maximum inventory capacity receive lower interaction priority.

## Controls, combat, and technical changes

- D-Pad Up can now recover from knockback states.
- The patch adjusts invulnerability windows during knockback and recovery.
- Ranged-weapon aiming now uses hold input and gets input buffering during sliding, rolling evasion, and standard Slash attacks.
- Fictions also lists fixes for voice-language settings resetting, several progression blockers, invisible barriers, fast-travel and campsite issues, boss-hit issues, and rendering/performance cases.

## What the patch does *not* confirm

The notes say Fictions is still working on additional updates. In particular, they list finishing skippable cinematics/cutscenes as future work. That means a player should not treat v1.0.10 as confirmation that every scene is skippable.

The patch also does not provide a universal fix for every PC crash, driver problem, or platform-specific graphics issue. Use the official crash-report steps for those cases.
