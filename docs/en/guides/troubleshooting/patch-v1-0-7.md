# Beast of Reincarnation Patch v1.0.7 Notes

<div class="meta"><span>Last checked: Aug 10, 2026</span><span>v1.0.7 / v1.005.000</span><span class="verified">Official patch notes</span></div>

<div class="quick-answer"><strong>Quick Answer</strong>v1.0.7 adjusts the camera and text size, prevents certain affinity conversations from playing back-to-back, makes Performance mode the default for cutscenes, expands Interact-button mapping, and includes gameplay, settings, balance, and bug fixes.</div>

## Confirmed changes

- Camera adjustments in and out of combat.
- Text-size adjustments; more subtitle-size work is planned.
- Certain affinity conversations now trigger once per day.
- Performance mode is now the default cutscene setting; existing players set to Cinematic must change it manually.
- The Interact button can be mapped independently through a drop-down menu.
- Boss adjustments across all difficulties and Normal-difficulty enemy-encounter adjustments.
- Fixes for button-icon settings, upscaling resets, V-Sync/resolution interaction, a Subcity 01 golem, and a cancelled Bloom Art interaction issue.

## Planned, but not dated

Fictions says more patches are planned and specifically names DLSS 4/4.5 (L/M), FSR4, further story-pacing adjustments, and more. It has not given a release date for those future items.
