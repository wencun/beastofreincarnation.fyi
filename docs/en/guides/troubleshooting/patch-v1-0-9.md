# Beast of Reincarnation Patch v1.0.9 (v1.007.000)

<div class="meta"><span>Released: Aug 24, 2026</span><span>Official patch summary</span><span class="verified">Based on Fictions’ v1.0.9 / v1.007.000 notes</span></div>

<div class="quick-answer"><strong>Previous patch</strong><a href="/en/guides/troubleshooting/patch-v1-0-10">Patch v1.0.10 / v1.008.000 is now the latest official note.</a> Patch <strong>v1.0.9 / v1.007.000</strong> is live. It adds ultrawide monitor support, DLSS/FSR frame-generation options, the first batch of skippable events and cutscenes, and fixes the Microsoft Store/Xbox PC issue that made upscaling features unavailable.</div>

## What changed for PC players

- **Ultrawide:** most ultrawide and super-ultrawide monitors are now supported.
- **Frame generation:** DLSS/FSR frame-generation options are available in the settings menu.
- **Xbox PC / Microsoft Store upscaling:** the official notes say the v1.0.8 issue that made upscaling features unavailable is fixed.
- **PC fixes:** the notes list fixes for keyboard confirmation on the Return Results screen, an Alt-Tab fast-travel issue, an unintended Bed Menu mouse action, and a keyboard/controller New Game+ soft lock.

If a graphics option still does not appear after updating, record your game version, store, GPU, driver version, and a screenshot of the settings menu before contacting support. Do not rely on third-party DLL replacements as an official fix.

## Cutscene and quality-of-life changes

- Some events and cutscenes can now be skipped by holding the Interact button; a skip indicator appears at the bottom right.
- Certain cutscenes before the final boss are now skippable.
- Charms can now be sold.
- Healing can be used immediately after taking damage, with less movement slowdown while Emma heals.
- The patch also includes performance optimizations for boss attack effects, Bloom Art command processing, and status-effect visuals.

Fictions says skippable cutscenes are being introduced in batches. Not every event is confirmed skippable yet.

## Still planned

The official notes list the following as future work, without dates:

- A post-processing toggle
- More skippable events and cutscenes
- Event and cutscene presentation improvements
- Blade Art and Bloom Art balance changes
- Water-submersion and invisible-wall collision adjustments
