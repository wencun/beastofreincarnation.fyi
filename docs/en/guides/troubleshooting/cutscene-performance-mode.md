# Beast of Reincarnation Cutscene Performance Mode

<div class="meta"><span>Last checked: Aug 10, 2026</span><span>Graphics setting</span><span class="verified">Official support steps</span></div>

<div class="quick-answer"><strong>Quick Answer</strong>Open <strong>Settings → Graphics → Frame Rate (Cutscenes)</strong>, then choose <strong>Cinematic (24 FPS)</strong> or <strong>Performance (same FPS as game settings)</strong>. Patch v1.0.7 changes the default to Performance mode, but existing players who already chose Cinematic must change it themselves.</div>

## Change the setting

1. Open **Settings** while in-game.
2. Select **Graphics**.
3. Open **Frame Rate (Cutscenes)**.
4. Choose **Cinematic (24 FPS)** or **Performance (same FPS as game settings)**.

Performance mode affects cutscene frame rate; it is not a promise that every gameplay frame-rate or crash issue is fixed.
