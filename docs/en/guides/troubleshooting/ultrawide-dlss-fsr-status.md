# Beast of Reincarnation Game Pass DLSS & Ultrawide Support

<div class="meta"><span>Last checked: Aug 26, 2026</span><span>PC · Steam · PC Game Pass</span><span class="verified">Official v1.0.9 status</span></div>

<div class="quick-answer"><strong>Quick Answer</strong>Fictions’ <strong>v1.0.9 / v1.007.000</strong> notes say the prior Microsoft Store/Xbox PC issue that made upscaling features unavailable has been resolved. The patch adds DLSS/FSR frame-generation options in Settings and supports most ultrawide and super-ultrawide monitors.</div>

## What v1.0.9 officially confirms

| Feature | Current official status |
| --- | --- |
| PC Game Pass / Microsoft Store upscaling | The v1.0.8 issue that made upscaling features unavailable is listed as fixed in v1.0.9. |
| DLSS / FSR frame generation | Implemented; options can be enabled from the Settings menu. |
| Ultrawide support | Implemented for most ultrawide and super-ultrawide monitors. |
| Every graphics issue on every PC | Not guaranteed. Fictions asks players to report any remaining problem with platform and hardware details. |

## If DLSS, FSR, or frame generation is still missing

1. Confirm that the installed version is **v1.0.9 / v1.007.000** or later.
2. Restart the game after the update and open the in-game Settings menu again.
3. Record the store used (Steam or PC Game Pass), game version, GPU, driver version, and a screenshot of the graphics menu.
4. Send those details to [Fictions Support](https://support.fictions.com/hc/en-us/categories/42992376012691-Beast-of-Reincarnation).

Do not treat a third-party DLL replacement, injector, or mod as an official fix. The patch notes confirm the in-game options only.
