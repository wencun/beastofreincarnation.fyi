# How Does Combat Work in Beast of Reincarnation?

<div class="meta"><span>Last updated: Aug 4, 2026</span><span>Version: Launch information</span><span>PC · PS5</span><span class="verified">Officially confirmed</span></div>

<div class="quick-answer"><strong>Quick Answer</strong>Combat combines Emma’s real-time sword actions with command-based skills for Koo. You directly move, evade, parry, and attack as Emma. When you open Koo’s command menu, the action slows, giving you time to select a technique. Successful parries help build points used for Koo’s skills.</div>

## Before you start

- This explains the officially demonstrated system, not a tested optimal build.
- Exact controls depend on platform and your selected layout.

## Steps

1. Control Emma directly to position yourself and use sword attacks.
2. Read the enemy’s attack and evade or parry it.
3. Build the resource used for Koo’s commands through successful defensive play.
4. Open Koo’s command menu when you need a tactical skill.
5. Choose a skill while the action is slowed.
6. Return to Emma’s real-time actions and continue the sequence.
