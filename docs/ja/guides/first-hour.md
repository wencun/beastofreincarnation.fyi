# 最初の1時間を始める前に知っておくこと

<div class="meta"><span>最終更新: 2026年8月4日</span><span>バージョン: 発売時情報</span><span>PC · PS5</span><span class="verified">公式確認済み</span></div>

<div class="quick-answer"><strong>クイック回答</strong>エマとクゥを中心とするシングルプレイのアクションRPGです。まずエマの移動、剣攻撃、回避、パリィを覚え、その後クゥのコマンドスキルを組み合わせます。スキルツリー、装備、霊石で戦い方を変えられるため、未検証の「最強ビルド」を序盤の必須条件と考えないでください。</div>

## 前提条件
- 使用機種と地域別の発売時刻を確認します。
- PCでは64ビット版Windows 11を確認し、詳細要件は公式ストアで照合します。
- シングルプレイに必要な通信条件は本ページでは未確認です。

## 手順
1. 最初の戦闘前に操作とアクセシビリティ設定を確認します。
2. 攻撃せずに移動と回避を練習します。
3. エマの基本的な剣攻撃を一つ覚えます。
4. 読みやすい敵の攻撃でパリィを練習します。
5. クゥのコマンドメニューを開き、進行の変化を確認します。
6. スキル、装備、霊石の説明を読んでからリソースを使います。

## うまくいかない場合
