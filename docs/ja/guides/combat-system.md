# 戦闘はどのような仕組みですか？

<div class="meta"><span>最終更新: 2026年8月4日</span><span>バージョン: 発売時情報</span><span>PC · PS5</span><span class="verified">公式確認済み</span></div>

<div class="quick-answer"><strong>クイック回答</strong>エマのリアルタイム剣戟と、クゥへのコマンド指示を組み合わせた戦闘です。エマを直接操作して移動、回避、パリィ、攻撃を行います。クゥのコマンドメニューを開くと進行が遅くなり、技を選ぶ時間が得られます。パリィ成功はクゥの技に使うポイント獲得につながります。</div>

## 始める前に
- 公式実演で確認された仕組みの説明であり、最適ビルドの実機検証ではありません。
- 正確なボタンは機種と設定により異なります。

## 手順
1. エマを直接操作し、位置取りと剣攻撃を行います。
2. 敵の攻撃を読み、回避またはパリィします。
3. 防御を成功させ、クゥのコマンド用リソースを蓄積します。
4. 戦術的な技が必要な場面でクゥのコマンドメニューを開きます。
5. 進行が遅くなっている間に技を選びます。
6. エマのリアルタイム操作へ戻り、攻撃を続けます。

<div class="ad-slot">広告枠 — 回答と手順の後</div>

## うまくいかない場合
メニューやボタンが異なる場合は、使用機種のゲーム内操作設定を確認してください。製品版で検証できるまで特定のボタン表記は掲載しません。
