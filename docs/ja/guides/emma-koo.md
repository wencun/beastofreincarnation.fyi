# エマとクゥには何ができますか？

<div class="meta"><span>最終更新: 2026年8月4日</span><span>バージョン: 発売時情報</span><span>PC · PS5</span><span class="verified">公式確認済み</span></div>

<div class="quick-answer"><strong>クイック回答</strong>エマは剣で戦い、植物のつるのような髪を移動や落下奇襲に使います。クゥはコマンドで選ぶスキルによって支援します。エマが即時の移動とアクションを担当し、クゥが進行の遅いコマンド画面から戦術的な技を繰り出す、一人と一匹の戦闘です。</div>

## 前提条件
- ここで説明する基本能力の進行条件は公式に確定していません。
- スキルの解放順とコストは製品版での検証が必要です。

## 手順
1. エマの剣アクションで直接戦います。
2. つる状の髪で移動できる地形を探します。
3. 高低差と位置取りを利用して、実演された落下奇襲を狙います。
4. クゥのコマンドメニューを開き、支援技を選びます。
5. スキルツリー、装備、霊石でプレイスタイルを調整します。

## うまくいかない場合
能力にストーリー進行や未公開の解放条件がある可能性があります。ゲーム内説明を確認し、未検証情報だけを根拠にリソースを使わないでください。
