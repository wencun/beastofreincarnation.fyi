# PC版の動作環境は？

<div class="meta"><span>最終更新: 2026年8月4日</span><span>バージョン: Steam掲載情報</span><span>Windows PC</span><span class="verified">公式確認済み</span></div>

<div class="quick-answer"><strong>クイック回答</strong>Steamの公式掲載では、64ビットのプロセッサとOSが必要で、最低OSはWindows 11です。このページで確認した情報源にはCPU、GPU、メモリ、容量、推奨構成の詳細値がまだ掲載されていません。推測で作られた要件表は利用しないでください。</div>

## 始める前に
- 64ビット版Windows 11を使用します。
- GPUメーカーの公式手順でドライバーを更新します。
- 空き容量を確保します（公式の必要容量はここでは未確認です）。

## 手順
1. Windowsの設定を開きます。
2. **システム → バージョン情報**を選びます。
3. **システムの種類**が64ビットであることを確認します。
4. Windows 11であることを確認します。
5. その他のパーツは公式の詳細値が公開されてから比較します。

<div class="ad-slot">広告枠 — 回答と手順の後</div>

## うまくいかない場合
起動できない場合はエラー全文を保存し、公式サポートまたはSteam更新情報を確認してください。再現確認なしにレジストリ、BIOS、セーブデータを変更する危険な手順は勧めません。
